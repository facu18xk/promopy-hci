# PromoPY — Portafolio HCI

Proyecto académico de Interacción Humano-Computadora (2026). PromoPY centraliza el descubrimiento de beneficios y reintegros bancarios en Paraguay.

**Integrantes:** Facundo Garay, Camila Grahl y Braian Miete.

- Portafolio (URL prevista, pendiente de publicación): https://facu18xk.github.io/promopy-hci/
- Demo navegable (URL prevista): https://facu18xk.github.io/promopy-hci/demo/
- Vista local del portafolio: [index.html](index.html).
- Vista local de la demo: [demo/index.html](demo/index.html).

El repositorio se organiza en `index.html` (portafolio), `css/` (estilos), `js/` (interacciones opcionales), `img/` (capturas optimizadas), `demo/` (recorrido navegable) y `anexos/` (evidencias originales).

La demo permite navegar las diez capturas originales, pero no es una aplicación funcional ni un prototipo Figma interactivo. No se aportaron resultados de evaluación ni un User Story Mapping original; el mapa presentado es una reconstrucción documentada.

## Publicación

Ejecutar `bash publicar.sh` desde la carpeta del proyecto con Git y GitHub CLI (`gh`) instalados y una sesión iniciada. El script crea un repositorio público nuevo, sube el contenido y configura Pages para publicar `main` desde la raíz. No sobreescribe repositorios existentes. Alternativamente, crear un repositorio público, subir estos archivos y en Settings → Pages seleccionar Deploy from a branch → main → / (root).

Revisar los anexos y sus enlaces externos antes de publicar, ya que el repositorio será público.
