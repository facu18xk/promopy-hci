# PromoPY — Portafolio HCI

Proyecto académico de Interacción Humano-Computadora (2026). PromoPY centraliza el descubrimiento de beneficios y reintegros bancarios en Paraguay.

**Integrantes:** Facundo Garay, Camila Grahl y Braian Miete.

- Portafolio (pendiente de publicación): https://facu18xk.github.io/promopy-hci/
- Demo navegable (pendiente de publicación): https://facu18xk.github.io/promopy-hci/demo/

Estructura prevista: `index.html` (portafolio), `css/` (estilos), `js/` (interacciones), `img/` (capturas), `demo/` (recorrido navegable) y `anexos/` (evidencias).

La demo recorre las diez capturas originales; no es una aplicación funcional. El User Story Mapping es una reconstrucción documentada y no se aportaron resultados de evaluación.
